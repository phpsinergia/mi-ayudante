FTPS	Con curl la diferencia es básicamente el esquema ftps:// y la opción --ftp-ssl (explicita AUTH TLS/SSL sobre el puerto 21). Si tu servidor usa FTPS implícito (puerto 990), añade --implicit-ftps. Fuera de eso la línea es igual que para FTP.

HTTP POST	En lugar de -u user:pass (Basic-Auth) mandamos JSON {"user":"…","pass":"…"}; el servidor valida y, si ok, devuelve el binario como cuerpo de la respuesta. Si tu endpoint exige un token en cabecera, sustitúyelo por -H "Authorization: Bearer $Token".
Ajusta tu backend HTTP para aceptar el JSON (o header) indicado y devolver 200 OK con el binario; recuerda poner Content-Disposition: attachment; filename="foo.zip" si quieres que curl lo guarde con ese nombre.
